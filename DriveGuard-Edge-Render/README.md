# DriveGuard Edge — Render Edition

Чистый минималистичный интерфейс для мониторинга состояния водителя. Проект готов для GitHub и Render: в корне уже лежит `render.yaml`.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:4173`.

## Деплой через Render

1. Создайте новый пустой репозиторий GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория. `package.json` и `render.yaml` должны находиться в корне.
3. В Render выберите **New → Blueprint**.
4. Подключите репозиторий и нажмите **Apply**.
5. Render выполнит `npm install && npm run build`, затем `npm start`.
6. Проверка сервера доступна по `/api/health`.

Альтернативно создайте **Web Service** вручную:

- Runtime: `Node`
- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- Health Check Path: `/api/health`

## Важное ограничение ESP32

Render не видит локальные адреса вида `192.168.x.x`. Публичный HTTPS-сайт также не может безопасно открыть обычный HTTP MJPEG-поток из домашней сети.

Для демонстрации сайт автоматически работает без камеры. Для настоящей ESP32 есть два варианта:

1. Запускать этот же проект локально на ноутбуке — тогда `http://192.168.x.x` работает напрямую через серверный прокси.
2. Создать защищённый HTTPS-мост к локальному edge-service, например через Cloudflare Tunnel, и ввести его HTTPS-адрес в поле устройства. Не публикуйте ESP32 напрямую и не открывайте порты 80/81 на роутере.

## Структура

```text
src/components/   интерфейсные модули
src/hooks/        подключение оборудования
scripts/          сборка и разработка
server.mjs        production-сервер и device proxy
render.yaml       автоматическая конфигурация Render
```

Сайт является исследовательским прототипом и не заменяет сертифицированные автомобильные системы безопасности.
